# Attendance Management System Using Face Recognition

An **AI-based Attendance Management System** that automates attendance recording using **face recognition** through a webcam. The system reduces manual effort, provides contactless attendance marking, and stores attendance records digitally.

## 📌 Features

* **Face Recognition-Based Attendance** – Automatically identifies registered users using facial features.
* **Webcam Integration** – Captures faces through a connected camera.
* **Automatic Attendance Marking** – Records attendance after successful face verification.
* **Contactless System** – Eliminates the need for manual registers or physical interaction.
* **Attendance Records** – Stores attendance information digitally for easy management.
* **Database Management** – Maintains user and attendance data in MySQL.
* **Web-Based Interface** – Provides an easy-to-use interface for managing the attendance system.
* **Role-Based Access** – Supports different access levels for system users.

## ⚙️ System Workflow

1. **User Registration**

   * User details and facial data are registered in the system.

2. **Face Detection**

   * The webcam captures the user's face.
   * OpenCV processes the camera frames.

3. **Face Recognition**

   * The captured face is compared with registered facial data.

4. **Attendance Verification**

   * If the face is successfully recognized, the user's identity is verified.

5. **Attendance Recording**

   * The system records the attendance along with the relevant date and time.

6. **Database Storage**

   * Attendance records are stored in the MySQL database for future reference.
